# Data Science Projects

Machine learning and statistical modeling projects from my coursework, built in Python with pandas, scikit-learn, matplotlib and seaborn.

| Project | What it does | Methods |
|---|---|---|
| [Iowa Housing Prices](iowa-housing-prices/) | Explains and predicts home sale prices in Ames, Iowa | EDA, linear regression, Lasso, Ridge, Elastic Net, random forest feature importance |
| [Ensemble Methods Case Study](ensemble-methods/) | Compares single trees with ensembles on two classification problems: news article popularity and spam detection | Decision trees, bagging, random forests, Naive Bayes, grid search |
| [Heart Failure Prediction](heart-failure-prediction/) | Predicts heart failure as a complication after a heart attack from clinical records | Logistic regression, random forest, KNN, imputation, class balancing |

## Running the notebooks

The notebooks were written in Google Colab. The datasets are included in each project folder; see each project's README for details.

```bash
pip install pandas numpy scikit-learn matplotlib seaborn statsmodels
```
